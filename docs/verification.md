# 验证范围

## 本地检查

```powershell
npm run check
npm test
npm pack --dry-run --ignore-scripts
```

语法检查与 9 项行为用例无需安装 npm 依赖、访问网络或提供模型凭据。用例覆盖白名单隔离、两种 persona 段落名、模型信息与工作目录保留、自定义文案保护、Windows 换行、幂等性、模型切换和配置校验。

打包内容包含 `package.json`、`index.js`、`cordis.patch.yml`、`README.md`、`CHANGELOG.md`、`LICENSE` 和本文档。GitHub 仓库另保留测试。

新环境仍需验证实际模型请求。插件显示“运行中”仅证明已加载，不能替代请求验收。本仓库提供本地验证命令，不配置远程执行或自动发布流程。
